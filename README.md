# Kaizen
A simple To-Do list/planner to become 1% better everyday

# Features
- Add tasks with an optional deadline
- Tasks are grouped as "Overdue", "Today", "Upcoming", "Later", and "No Deadline"
- Reminder lines for tasks that are overdue or due today
- Categories you can rename, recolor, add, and delete
- Progress ring and per-category progress bars
- Tasks save automatically in your browser
